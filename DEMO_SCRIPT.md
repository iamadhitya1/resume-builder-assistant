# Demo script (about 10 min talk + Q&A)

Start: `streamlit run app.py` -> http://localhost:8501. Keep "Use Ollama LLM" OFF (fast, never fails). Turn it on once at the end if the network is fine.

## 0. Pitch (1 min)
"Students lose interviews at the resume stage. Our assistant builds the resume, scores it like an ATS, recommends roles, coaches via chat, and gives the placement cell a campus-wide view."

## 1. Build Resume (3 min)
- Student: Karthik Iyer, role Cloud/DevOps. Score ~54.
- Click **Auto-generate summary**, then **Improve project bullets** (weak "Used/Worked on" become action verbs + metric prompts).
- Add a metric to a bullet, add `kubernetes, ci/cd` to skills. The score on the right rises live.
- **Save version** (history chart shows improvement), then download HTML (print to PDF).

## 2. ATS Analyzer (2 min)
- Show the 4-part breakdown: skills match, keyword (TF-IDF), sections, impact bullets.
- Paste a different real JD to show matched/missing skills change.

## 3. Job Match (1.5 min)
- "ChromaDB vector search + skill overlap." Show best-fit roles and the learning plan.

## 4. Career Chat (1.5 min)
- Click the quick buttons: ATS score, missing skills, jobs, rewrite bullets, interview questions.
- Optional: toggle Ollama LLM; answer is grounded on the computed facts.

## 5. Campus Analytics (2 min)
- 80 synthetic students: readiness split, branch averages, demand vs supply of skills, top training gaps, at-risk list, CSV report download.
- "Actionable insight": the placement cell sees which skills to teach first.

## Tech stack line
Streamlit, Python, Pandas, SQLite (persistence), ChromaDB (vector search), scikit-learn (TF-IDF), Ollama (optional LLM), offline fallback.

## Likely questions
- **Is data real?** Synthetic, generated by `data_gen.py` (seeded).
- **LLM hallucination?** Scores and gaps are computed deterministically; the LLM only phrases advice.
- **Scale/next steps?** Real resume PDF parsing (OpenCV/OCR), JD scraping, per-college dashboards.
